<h2>Para la ejecución del programa solo se necesita:<h2> 
</div>

- La carpeta `Lab_10` (contenidos de Lab_10.zip)
- Mover todos los scripts dentro de la carpeta `scripts` hacia la carpeta recién extraída (`Lab_10`)

> Lo obtenido de hacer esto es lo que se muestra en la carpeta `Lab_10_INICIO`

Luego, solo correr el archivo *RUN.bash*:
```
bash RUN.bash
```

> Lo obtenido de correr este archivo es lo que se muestra en la carpeta `Lab_10_FIN`

<div align="center">
<h2>Información:<h2>
</div>


- La carpeta `scripts` contiene todos los scripts de bash creados
- La carpeta `all_csv` contiene todos los csv de `Lab_10_FIN`
- El archivo *RUN.bash* es el único que se mantendrá en la carpeta original, los demás scripts se mueven a `Obtencion_Aminoacidos` (creada por el mismo *RUN.bash*)
