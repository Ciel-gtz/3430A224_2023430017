Todos los scripts tienen que estar dentro de la carpeta con los pdb para funcionar, de ahí solo hay que correr:
```
bash RUN.bash
```
Esto se muestra en la carpeta `Lab_10_INICIO`

- La carpeta `scripts` solo contiene los scripts de bash
- La carpeta `all_csv` contiene todos los csv de `Lab_10_FIN`
- El archivo *RUN.bash* es el único que se mantendrá en la carpeta original, los demás scripts se mueven a `Obtencion_Aminoacidos` (creada por el mismo *RUN.bash*)
